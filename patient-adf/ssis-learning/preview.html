Control Flow orders tasks. Data Flow moves rows.
The included package uses three Execute SQL tasks, so it has no Data Flow task. A full SSIS ETL package would add a Data Flow task for each source table. Inside one, you would see components like these:

Then an Execute SQL task can load dimensions and facts with a stored procedure. This diagram is explanatory; those ETL components are not included in the read-only package.
Use a separate staging area for a future SSIS ETL exercise. Your live ADF pipeline already owns the shared staging tables.


Open the actual package
  1. Install a compatible Visual Studio edition and the Microsoft SQL Server Integration Services Projects extension.
  2. Create a new Integration Services Project.
  3. Right-click SSIS Packages → Add Existing Package → File System and choose Diamond_SSIS_Learning.dtsx.
  4. Double-click the package to view Control Flow. Use the designer's Auto Layout command if the tasks overlap.
  5. Edit the two connection managers, select Microsoft OLE DB Driver 19 for SQL Server and configure your Microsoft Entra account. Test each connection.
The package is for an interactive desktop session. Azure CLI sign-in is not reused by the OLE DB driver. No Azure-SSIS integration runtime has been provisioned.
